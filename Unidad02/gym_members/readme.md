# Dataset de Gimnasio y Fitness

 Este dataset proporciona una descripción detallada de las **rutinas de ejercicio, características físicas y métricas de fitness** de los miembros de un gimnasio.

 Cuenta con **973 registros** e incluye indicadores clave de rendimiento, como la frecuencia cardíaca, las calorías quemadas y la duración de los entrenamientos. También incorpora información demográfica y niveles de experiencia, lo que permite analizar patrones de entrenamiento, progresión deportiva y tendencias relacionadas con el estado físico.

 ## Características principales

 | Variable | Descripción |
| --- | --- |
| **Age** | Edad del miembro del gimnasio. |
| **Gender** | Género del miembro (`Male` o `Female`). |
| **Weight (kg)** | Peso del miembro en kilogramos. |
| **Height (m)** | Altura del miembro en metros. |
| **Max\_BPM** | Frecuencia cardíaca máxima durante las sesiones de entrenamiento, medida en latidos por minuto. |
| **Avg\_BPM** | Frecuencia cardíaca promedio durante las sesiones de entrenamiento. |
| **Resting\_BPM** | Frecuencia cardíaca en reposo antes del entrenamiento. |
| **Session\_Duration (hours)** | Duración de cada sesión de entrenamiento, expresada en horas. |
| **Calories\_Burned** | Total de calorías quemadas durante cada sesión. |
| **Workout\_Type** | Tipo de entrenamiento realizado, como `Cardio`, `Strength`, `Yoga` o `HIIT`. |
| **Fat\_Percentage** | Porcentaje de grasa corporal del miembro. |
| **Water\_Intake (liters)** | Cantidad de agua consumida diariamente durante los entrenamientos, expresada en litros. |
| **Workout\_Frequency (days/week)** | Número de sesiones de entrenamiento realizadas por semana. |
| **Experience\_Level** | Nivel de experiencia del miembro: principiante (`1`), intermedio (`2`) o experto (`3`). |
| **BMI** | Índice de Masa Corporal (IMC), calculado a partir del peso y la altura. |

## Posibles aplicaciones

 Este dataset es adecuado para:

 - Analizar los **hábitos de ejercicio** de los miembros.
- Estudiar la relación entre **actividad física y características corporales**.
- Analizar la relación entre **frecuencia cardíaca, duración del entrenamiento y calorías quemadas**.
- Modelar la **progresión del nivel de experiencia** de los atletas.
- Identificar patrones relacionados con el **tipo de entrenamiento y el rendimiento físico**.
- Explorar tendencias entre variables demográficas y métricas de fitness.
- Desarrollar modelos de **análisis predictivo y aprendizaje automático** relacionados con el rendimiento deportivo.
- Realizar análisis estadísticos sobre **intensidad, resistencia y hábitos de entrenamiento**.

 ## Resumen

 En conjunto, el dataset ofrece una visión integral de diferentes aspectos del **entrenamiento físico y el rendimiento de los miembros de un gimnasio**, combinando variables demográficas, antropométricas, fisiológicas y relacionadas con el ejercicio.
